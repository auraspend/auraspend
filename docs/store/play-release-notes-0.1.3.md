# Play release notes — 0.1.3

For the Play Console's **What's new** field (limit: 500 characters per
language), uploaded with `AuraSpend-V0.1.3.Alpha.aab` (versionCode 4). Plain
text only — Play does not render Markdown.

## English (en-US) — 431 characters

```
What's new in 0.1.3

• Watch categorisation live — progress, how many messages are waiting, and a summary when it finishes.
• One quiet progress notification per run, instead of many.
• Fixed: real ICICI card spends are no longer silently dropped; reversals and bill-payment credits record correctly; dates in messages are read properly.
• The categorisation screen now works even if you skip the optional on-device model download.
```
